## Close all tabs in VS Code

### Keyboard Shortcut

Press `Ctrl + K` then `W` to close all open editor tabs at once.

> Make sure to press `Ctrl + K` first, release, then press `W`.

### Alternatives

| Action | Shortcut |
|---|---|
| Close all tabs | `Ctrl + K` → `W` |
| Close current tab | `Ctrl + W` |
| Close all via menu | File → Close All Editors |
